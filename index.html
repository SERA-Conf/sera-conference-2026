SERA Conference 2026 — free prototype Open index.html in a browser to view it. This is an original mobile-first conference programme prototype inspired by the interaction the user liked in Bella Times. It contains fictional placeholder programme content. Features: two-day timetable, live-demo “happening now” line, search, favourites saved locally in the browser, session details, responsive mobile layout, SERA logo. The prototype is designed to be published for free on GitHub Pages or Cloudflare Pages.
